# Güvenlik

Güvenlik açığına ilişkin parola, kişisel veri veya çalışır saldırı ayrıntılarını herkese açık issue içine yazmayın. GitHub deposunda Private vulnerability reporting etkinse o kanalı, değilse depo sahibiyle özel iletişimi kullanın.

Bu başlangıç sürümü kimlik doğrulama ve sunucu tarafında yetkilendirme içermez. Gerçek kullanıcı veya finans verisiyle üretime alınmadan önce bu katmanlar, tenant izolasyonu testleri, işlem kayıtları, yedekleme ve veri saklama politikaları tamamlanmalıdır. Compose içindeki geliştirme parolası üretimde kullanılmamalıdır.
